**Zenthos Gym**

Membership, check-in and renewals for gyms running one or many branches.

**Features**

- Member app with membership status, days remaining and renewals
- Entrance QR check-in with distinct audio for active, expired and repeat scans
- Live front-desk console with instant audible alerts
- Renewals Due list so members are contacted before they lapse
- Referral programme with per-member invite links and automatic rewards
- Admin control of branches, plans, pricing, staff and system rules
- Bank transfer with proof upload, confirmed at the front desk
- Installable PWA

**Tech stack**

- Next.js, React, TypeScript
- Tailwind CSS
- Supabase (Postgres, auth, realtime, storage)
- Paystack
